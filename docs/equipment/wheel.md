# Wheel
{: .no_toc }

Sticks for the spokes, planks for the rim and hub. You need two to build a [Horse Cart](horse-cart).
{: .fs-5 .fw-300 }

---

## Crafting

{% include craft.html id="wheel" %}

**Any wood type works.** The recipe uses the `#minecraft:planks` tag, so mix and match whatever you have. You need **two wheels** per cart.

---

## What it's for

A wheel does nothing on its own. Pair two with planks and slabs to build the [Horse Cart](horse-cart).

{: .note }
> The wheel counts as a Better Horses item, so it works as the ingredient for crafting a spare [Stable Handbook](stable-handbook).
