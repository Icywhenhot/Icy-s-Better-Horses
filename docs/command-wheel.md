# The command wheel

## Opening it

Look at a horse you own and press <kbd>R</kbd>. A radial menu opens with five wedges. Pick one to issue the command, or click outside the wheel to cancel without changing anything.

The wheel only works on **your own** horses, and only when one is in view.

---

## The five commands

### Follow

The horse trails after you, stopping about **3 blocks** away so it doesn't shove you around. It keeps up at 1.2× its normal movement speed, so a bonded horse follows briskly.

This is also the state a horse switches to when you [whistle](ownership-and-bonding#whistling-for-your-horse) for it from nearby.

### Stay

The horse holds position exactly where it is and won't wander off. Use it when you're heading somewhere a horse can't follow: down a ravine, into a cave, through a one-block gap.

### Wander

The horse grazes and roams freely inside a **32×32 area** centred on wherever you gave the command (16 blocks in each direction). If it drifts past the edge it paths back in. Good for a pasture or a fenced paddock where you want it to look alive without leaving.

### Set Home

Marks the horse's current position as its **home**, then puts it into Stay. You'll see:

> Home location set.

Each horse remembers one home. Setting a new one replaces the old.

### Return Home

Sends the horse back to its saved home. If it has no home set yet you'll get:

> No home set for this horse.

{: .tip }
> Set a home at your base, and you can whistle the horse to you from anywhere, ride it out, then send it home from the [roster screen](managing-your-horses) without riding back.

---

## Command reference

| Command | Effect | Notes |
|:---|:---|:---|
| **Follow** | Trails you, stops at ~3 blocks | Moves at 1.2× speed |
| **Stay** | Holds position | Survives you logging out |
| **Wander** | Roams a 32×32 area | Centred where the command was given |
| **Set Home** | Saves this spot as home | Also switches the horse to Stay |
| **Return Home** | Paths back to the saved home | Needs a home to have been set |
