# Andalusian
{: .no_toc }

An agile, strong Iberian breed with a thick mane, common across open meadows.
{: .fs-5 .fw-300 }

1. TOC

---

## Class: War

Never spooks, never rears when struck, medkits last twice as long, hits hardest.

See [Breeds](index) for what every class shares.

## Breed ability: Courage

| Bond | Effect |
|:---|:---|
| 0 | rider takes reduced damage while mounted |
| 40 | stronger reduction |
| 100 | **Second Chance**: a killing blow is taken by the horse instead, which survives on one heart. Long cooldown. |

## Coats

3 coats, each its own texture — these breeds don't use vanilla's coat and marking system.

## Where to find them

Open meadows and light woodland:

- Meadow
- Cherry Grove
- Flower Forest
- Plains
- Forest

{: .tip }
> Hold an [Upgraded Saddle](../equipment/upgraded-saddle) and look at a wild horse to check its breed, gender, speed, and jump before you commit to taming it.
