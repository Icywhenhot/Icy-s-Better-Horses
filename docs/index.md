# Icy's Better Horses
{: .fs-9 }

Vanilla horses are an early-game novelty you abandon the moment you find elytra. Better Horses makes them worth keeping: a mount you own, bond with, equip, breed, and actually travel on.
{: .fs-6 .fw-300 }

[Get started](getting-started){: .btn .btn-primary .mr-2 }
[Browse the breeds](breeds/){: .btn }

## What the mod adds

| System | What it does |
|:---|:---|
| [Ownership & bonding](ownership-and-bonding) | Taming claims a horse as yours. Bond grows 0–100 and raises speed and jump by up to **+75%**. |
| [Command wheel](command-wheel) | A radial menu to make a horse follow, stay, wander, or return to a saved home. |
| [Fifteen breeds](breeds/) | Real breeds with their own coat palettes and biome ranges, plus gender and mixed-breed foals. |
| [Genetics & breeding](genetics) | Gender-gated breeding, 50/50 breed inheritance, and stat rolls that can beat both parents. |
| [Tack & gear](equipment/) | An upgraded saddle with five gear slots: hooves, medkit, stabilizer, chest, hitchpost. |
| [Horse carts](equipment/horse-cart) | A four-seat cart your horse tows, with an optional double-chest of storage. |
| [Riding fixes](riding) | Auto-ride, free look, leaf passthrough, water floating, higher step height, two riders per horse. |
| [Horse roster](managing-your-horses) | A screen listing every horse you own, with its live coordinates, so you can whistle, send home, or disown from anywhere. |
| [Commands](commands) | `/horse trust <player>` to let a friend ride every horse you own, without giving up the rest of ownership. |

## Requirements

| | |
|:---|:---|
| Minecraft | 26.2 |
| Mod loader | Fabric, loader 0.19.3+ |
| Java | 25 or newer |
| Required | [Fabric API](https://modrinth.com/mod/fabric-api), [GeckoLib](https://modrinth.com/mod/geckolib) 5.5.0+, [Modonomicon](https://modrinth.com/mod/modonomicon) |
| Optional | [Mod Menu](https://modrinth.com/mod/modmenu) and [Cloth Config](https://modrinth.com/mod/cloth-config) for the in-game settings screen |

{: .note }
> Modonomicon is a **hard** dependency and the game will not start without it. It powers the in-game **Stable Handbook**, which covers the same ground as this wiki from inside the world.

## Where to start

New to the mod? Read [Getting started](getting-started). It takes you from taming your first horse to a fully equipped mount.

Looking for a specific number? [Bonding](ownership-and-bonding) has the stat tables, [Recipes](recipes) has every craft in one place, and [Configuration](configuration) covers the server toggles.
